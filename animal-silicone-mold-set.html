      Description

      This three-piece animal silicone mold set includes a sea turtle, gecko and frog. The flexible silicone helps release details such as the turtle shell and gecko toes. Cast with epoxy resin for glossy decorative figures or plaster for matte pieces you can paint. For UV resin, follow the resin maker’s layer depth and curing instructions.
